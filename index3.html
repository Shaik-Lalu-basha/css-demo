Animations
Attributes & purpose
animation-name: the @keyframes block to run
animation-duration: how long one cycle takes
animation-timing-function: easing (linear, ease-in, cubic-bezier)
animation-delay: start delay before first cycle
animation-iteration-count: how many times to repeat (or infinite)
animation-direction: normal, reverse, alternate
animation-fill-mode: how styles are applied before/after animation
transform: translate/rotate/scale applied inside keyframes or on the element
Controls
1s
Transforms applied alongside animation (translateX, rotate, scale)
Quick notes
Keyframes: Divide animation into logical frames using percentages (0%..100%). Use transforms inside frames for performant animations (GPU-accelerated).
